# Benim Yapay Zekâm — GitHub APK build

1. GitHub'da yeni bir repository oluştur.
2. Bu ZIP'in içindeki TÜM dosyaları repository'nin köküne yükle.
3. Actions > Build Android APK > Run workflow.
4. İşlem bitince Artifacts bölümünden `BenimYapayZekam-debug` dosyasını indir.
5. İndirdiğin ZIP içindeki `app-debug.apk` dosyasını telefona kur.

Bu sürümde Android Gradle Plugin sürümü ve `app` modülü düzeltildi.
